## Description

[Tastyble Notification Service](https://github.com/tastyble/notification-service-client) framework TypeScript starter repository.

## Installation

```bash
Clone the repo and run the commands:

$ yarn install
```

## Running the app

```bash
# development
$ yarn run start

# watch mode
$ yarn run start:debug

# production mode
$ yarn run start:prod
```

## Test

```bash
# unit tests
$ yarn run test

# watch mode
$ yarn run test:watch

```

## Contribution

There are two existing branches available.

- **master** is for main production instance of the server. Please do not tamper with this branch for obvious reasons.
- **staging** is for the staging instance of the app. This instance is used for remote testing instance.

**PS: All pull requests should be created on the staging branch before been merged to the master branch.
To contribute; create a branch from the master branch using the name of the feature you are adding.**

## Guidelines

- Before installation of any dependency, check with the team lead.
- Comment your code simply and understandably.
- Write tests
- Follow existing code structure.
- Make sure every task is 100% correct and complete before marking as complete.
